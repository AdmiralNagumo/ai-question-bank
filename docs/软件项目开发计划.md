## 引言

### 编写目的

本文档旨在明确 AI+题库智能教学平台的项目计划，作为团队开发进度管理、任务分配和里程碑验收的依据。本文档面向全体开发团队成员及课程评审教师。

### 背景

本项目面向高校教育场景，旨在构建一个多教师、多学生、多租户的智能题库与试卷管理平台。当前教育信息化过程中，题库系统普遍缺乏 AI 辅助解题能力，师生协作效率低下，知识沉淀困难。本平台通过集成大模型能力，实现题库管理、试卷组织、AI 智能解答、分支对话树讨论等功能，为教学场景提供完整的数字化解决方案。

| 项目名称 | AI+题库智能教学平台 |
|----------|---------------------|
| 项目简介 | 面向高校教育的多租户智能题库与试卷管理平台。支持教师管理题库/试卷并配置 AI 解答，学生提交题目、查看 AI 解答并在分支对话树中追问，管理员负责全局管理与审计。技术栈：C11 后端（libmicrohttpd + SQLite3 + libcurl + cJSON）+ 纯 HTML/CSS/JS 前端。 |

## 项目目标与范围

### 项目目标

| 目标类型 | 描述 |
|----------|------|
| 功能目标 | 构建多租户题库与试卷管理平台，集成大模型实现 AI 智能解答与分支对话树讨论；支持用户认证、题目 CRUD、试卷管理、额度管理、管理审计等完整功能 |

## 项目进度计划

### 开发模型

采用**迭代增量开发**模型，按里程碑分阶段交付，共 9 个 Sprint（2026/10/08 — 12/28），每 1–2 周一个 Sprint，周二晚小组会议同步进度。

### 里程碑

| 里程碑 | 日期 | 验收标准 | 状态 |
|--------|------|----------|------|
| M1 - Demo 实现 | 10/08 — 10/27 | 最小可用系统：用户认证+题库读写+试卷管理+AI解答，部署上线 | ✅ 已达成 |
| M2 - 功能完善 | 10/27 — 12/10 | 完成 P0+P1 全部功能（F01~F14），优化使用体验 | 🔶 进行中 |
| M3 - 高并发支持与交付 | 12/10 — 12/28 | 性能改造支撑高并发，服务监控，最终文档+部署包交付 | ⬜ 待开始 |

> **状态（2026-10-13）**：M1（10/08—10/27）进行中——CI 全绿、用户认证完整实现（含注册）、题目只读 API 上线、kv_store 存储层（PR #5）已合入、前端三页就绪；待完成：题目写接口、试卷管理（F03）、LLM 接入（F05）、生产部署（I02）。

## 风险管理

## 质量保证

### 编码规范

- C11 标准，`gcc -std=c11 -Wall -Wextra` 零警告
- Conventional Commits 提交信息
- 详情见 `docs/AGENT.md` 和 `CONTRIBUTING.md`

### 测试策略

| 层级 | 负责 | 内容 |
|------|------|------|
| 单元测试 | 各开发者 | C 函数级测试 |
| API 测试 | 卢恒毅 | 冒烟测试 case_*.sh |

| CI 自动测试 | GitHub Actions | 每次 push/PR 自动运行 |

- Reviewer 检查清单见 `CONTRIBUTING.md`
