## 发现并修复的问题

1. **工具前讲解丢失**：原实现只返回最后一段助手文字。现汇总本轮工具前后可见文字，内部思考不展示。
2. **零系数概念错误**：明确a=0时是退化方程/常数等式，不能称为一元一次方程。
3. **无依据错因猜测**：真实接口曾出现“11−3=7”等虚构过程。对可识别的仅答案输入，服务按题干系数确定性代入，只给核验结论并请求过程；原不可靠文字不进入追问历史。
4. **提示层级过细**：一级只给方向，二级给一般关系，三级只给一个下一步，不给已代入的最终表达式。
5. **负耗时**：系统时钟调整导致原测量为负，队列预算和评测耗时改用单调时钟。
6. **报告易丢失**：评测逐题保存、支持按案例运行及恢复，模型/代码变化时拒绝混合恢复。

## 本地复现

在WSL项目中配置ai-service/.env后运行：

```bash
cd ~/projects/ai-question-bank
make -C ai-service eval-real
```

默认离线检查：`make -C ai-service eval`。真实评测会产生模型调用用量，输出报告位于ai-service/eval/reports。

前端继续使用接口档案1.1：mode可选solve/hint/review，review传student_answer，切换模式新建对话。
