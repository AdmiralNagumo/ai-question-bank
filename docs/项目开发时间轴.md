## 6. 风险与缓冲

| 风险项 | 影响 | 应对策略 |
|--------|------|----------|
| Sprint 内任务未完成 | 里程碑延迟 | 周二会议评估，将未完成任务移到下个 Sprint，削减低优先级功能 |
| AI API 调用不稳定 / 限流 | AI 解答功能不可用 | 增加重试机制 + 降级提示 + 预备多供应商 |
| 高并发改造影响现有功能 | 回归 Bug | 每个 I 类任务搭配自动化回归测试 |
| 成员时间冲突（期中/期末） | 产能下降 | 提前将非关键路径任务分配到低负载时段 |
| 向量检索引入复杂度高 | 重复检测延迟 | 先用关键词匹配降级方案，后续迭代引入向量检索 |
